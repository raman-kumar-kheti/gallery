# Frontend Web App

This is the Next.js frontend application for the Gallery project.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Environment Variables:
   This project relies on the root `.env` file for its primary configuration. 
   If you need to override any variables locally during development, you can add them to the `.env.local` file in this directory.

3. Run the development server:
   ```bash
   npm run dev
   ```

## Commands
Please refer to `package.json` for all available commands.
